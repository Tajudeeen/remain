        Developer and operator setup ↗
        1. In your Remain checkout, copy .env.example to .env.local if the local file does not exist.
        2. Add your working developer key and matching secret there. Keep this file private. Set REMAIN_LOCAL_READ_ONLY=true.
        3. Run npm run dev, then open http://127.0.0.1:3000/#live.
        4. Discover your account and choose a held stock. Explore a cash target with an exposure floor, or prepare a manual inspection amount below. Both remain read-only.

        API keys stay on your computer. Selected holdings and cash previews stay in local page memory and expire. The RFQ structural report omits your account, amount and raw quote. Clear removes the account, inputs and observed results.

        Wallet balance reads are on-chain observations, not market valuations. Pricing, tradability and settlement require independent checks. The separate demo planner never changes your wallet balance.
