## Adversarial fixes in PR #57

- Wallet supported-stock scan: upper-bound the initial/final wallet account and chain reads, handle timeout and abort, do not infer zero holdings from failed RPCs. Regress against an inert provider and a revoked scan.
- Status console: limit received *bytes during streaming* (not just a Content-Length header); reject oversized chunks, malformed UTF-8 and cancelled reads.
- Real wallet entry: top-nav Connect action opens wallet selection instead of merely scrolling to a page. No automatic signing, approval or transaction.
- Simulator: reconcile local fictional order history with cached cash and positions before restoring a session. Check expiry and exact synthetic cash minimum against an independent input-size oracle.
- UI: a simulated closed underlying market with explicit permission is marked **CAUTION**, not an ordinary green PASS. Browser tests exercise unapproved and approved cases.
- Documentation: source is already public; source-release language in older milestone records is historical, not current.

The PR is not called complete until its **latest** SHA passes `npm run verify`, coverage, image smoke and real Chromium scenarios. Passing fixtures are not an adversarial security certificate.
